# Фитнес-календарь 🏋️‍♂️

Простое веб-приложение для отслеживания посещений спортзала.

## Особенности
- ✅ Адаптивный дизайн для iOS и десктопа
- 🎨 Циклическая смена цветов (красный/зеленый)
- 💾 Локальное сохранение данных
- 📱 Оптимизация для iPhone 13 Mini
- 🖥️ Hover-эффекты для десктопа
- 📊 Импорт/экспорт данных

## Использование
1. Откройте в браузере
2. Добавьте на главный экран (iOS)
3. Отмечайте дни тренировок

## Технологии
- HTML5, CSS3, JavaScript
- Local Storage
- GitHub Pages
